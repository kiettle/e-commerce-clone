# Load-test baselines

Successful flash-sale load runs write one Markdown file per profile in this
directory. Review and commit a baseline when it provides a useful comparison
for the same machine and stack configuration.

Baselines include CPU, memory, operating system, profile inputs, latency
percentiles, business-conflict counts, and post-run database invariants. They
describe local or CI development behavior only and must not be used as a claim
of production capacity.
